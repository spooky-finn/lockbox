# lockbox

Локальный менеджер паролей с TOTP-кодами. Всё хранится в одном
зашифрованном файле `.lbx`, приложение никогда не выходит в сеть.

Пока проверено только на macOS.

## Запуск

```sh
cd lockbox
cargo run --release
```

При первом запуске — «Создать хранилище…» и место для файла вне репо
(`*.lbx` в `.gitignore`, но лучше не держать его рядом с кодом). Последний
открытый файл запоминается в `~/Library/Application Support/lockbox/config.json`;
кнопка «Забыть путь» убирает его оттуда.

## Как защищены данные

- Мастер-пароль → Argon2id (256 МиБ, 3 прохода) → HKDF → ключ
  XChaCha20-Poly1305. Шифруется всё содержимое целиком, заголовок файла
  тоже защищён от подмены.
- Сохранение атомарное: временный файл → fsync → переименование;
  предыдущая версия остаётся рядом как `.lbx.bak`.
- Ключ и записи стираются из памяти при блокировке и закрытии окна.
- Скопированный пароль или код помечается для менеджеров буфера как скрытый
  и стирается из буфера через 20 с — если там всё ещё он.

## Иконки

Логотипы сервисов — из [Simple Icons](https://simpleicons.org) (версия в
`assets/SIMPLE_ICONS_VERSION`), вшиты в приложение: lockbox их не скачивает.
Иконка подбирается по домену URL записи (`mail.google.com` → Gmail,
остальное под `google.com` → Google, `gitlab.com` → GitLab); если не нашлась —
первая буква названия на цветном квадрате. В правке записи можно выбрать любую
иконку из набора.

Домены, которые не совпадают с названием иконки, лежат в
`assets/icon_domains.txt`. После правки или для новой версии набора:

```sh
curl -fsSO https://registry.npmjs.org/simple-icons/-/simple-icons-<версия>.tgz
tar -xzf simple-icons-<версия>.tgz
python3 -I tools/build_icons.py package
```

Набор распространяется под CC0, но сами логотипы — товарные знаки их
владельцев: см. `assets/DISCLAIMER-simple-icons.md`.

## Touch ID

Включается флажком «Touch ID» в открытом хранилище. Мастер-пароль всё равно
нужен: каждые 7 дней, после смены набора отпечатков в системе и если Touch ID
не сработал.

**Ограничение.** Ключ хранилища лежит в связке ключей (элемент `lockbox`), а
отпечаток проверяет сам lockbox. macOS не привязывает этот элемент к пальцу:
программа, которой вы разрешите доступ к элементу `lockbox` («Разрешать
всегда»), получит ключ без Touch ID. Настоящая привязка требует подписи с
аккаунтом Apple Developer — без неё macOS отвечает `errSecMissingEntitlement`.
После каждой пересборки macOS один раз спросит, можно ли lockbox читать этот
элемент: подпись меняется.
