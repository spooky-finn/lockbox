Security fixes 2026-11-01

- Sync: public signatures/authority checked before journal admission. Unknown
  dependencies use separate 128-object / 8 MiB quarantine. Invalid bytes dropped;
  bounded hash/error diagnostics retained. Outbox capacity stays independent.
- Legacy mixed journals: cleanup after witness verification; durable commit
  before signing. Failed cleanup stays pending. Read-only backups untouched;
  authenticated fork evidence and exact signing intents preserved.
- Icons: bundled default. Security setting opts into selected-site lookup.
  Same HTTPS origin, public IPv4/IPv6, pinned DNS, redirects/proxies disabled.
  Raster MIME allowlist. User accepts unencrypted persistent icon caching:
  `lockbox/favicons/v1` survives locking/restarting. Icons expire after 30 days;
  failures retry after five minutes. Unix directories 0700, files 0600.
  Startup no longer deletes cache. Bounded raster validation also applies on read.
- Files: bounded regular-file reads, including identity, import and Touch ID ID
  lookup. Vault limit 256 MiB; identity limit 64 KiB. Saves respect vault limit.
  Truncated ciphertext rejected before hashing. FIFO paths cannot block opening.
- KDF: max 512 MiB, six passes, combined 768 MiB-passes. Creation default remains
  256 MiB / three passes. Argon2 working arena zeroized on every exit.
- Autofill: checks associated submit controls, including external buttons and
  image inputs. GET overrides and cross-origin action overrides refused during
  inspection and fill. One-use document token retained.
