Desktop draft writer

- One lazy writer per unlocked vault. One commit in flight. Move live Vault
  and both leases to writer. Reuse upsert and durable signing transaction.
- UI keeps draft plus previous search metadata. No copied key, journal,
  password, TOTP, note or attachment in search snapshot. Snapshot cannot save.
- Edits during commit set new deadline. Save or navigation waits for latest
  snapshot. Failed commit returns live Vault, retains draft, cancels navigation.
- Sync polls resume when writer returns Vault. Other vault commands gated
  during write. Completion wakes window. Tab state owns receiver across switches.
- Lock and graceful window exit drain pending commit, flush latest edit, drop
  secrets and leases. Worker disconnect locks session. No result can reopen it.
