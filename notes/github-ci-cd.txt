- Entry points: ci.yml tests branch pushes only. release.yml handles main pushes + manual releases. Separate workflows; release never calls CI or waits for test results.
- Validation: formatting/browser job and three-OS Rust matrix run independently. CI passed requires both. Strict Clippy, all-target tests, doctests retained.
- Release preparation: default branch only; X.Y.Z matches Cargo.toml, Cargo.lock, extension manifest. Push compares prior version; unchanged skips packaging; decrease rejected. Manual release defaults draft.
- Scheduling: push CI runs independently of release preparation/builds. Native + browser packaging run in parallel after preparation; require release=true. No tests or smoke tests in release workflow.
- Publication boundary: prepare + all native builds + browser packaging must succeed. CI failure never blocks release; commits with failing tests can publish. Only publisher gets contents:write. Tag rechecked before creation; target remains triggering SHA. Version, artifact, checksum guards retained.
- Cancellation: CI superseded per branch. Release runs keyed by SHA, independent of CI; unchanged-version pushes cannot replace pending release.
- Build resources: Rust 1.95.0 pinned; OS/architecture/profile dependency caches; default branch writes, other branches restore. Debug symbols + incremental disabled; two build/test workers bound memory.
- Assets: macOS ARM/Intel app ZIPs, Linux amd64 deb + tar.gz, Windows amd64 ZIP, Chrome/Firefox ZIPs, SHA256SUMS. Native/browser packaging read validated version; asset verifier rejects incomplete/stale sets.
- Packaging contracts: Linux calculates runtime dependencies, registers desktop entry + lockbox://. macOS ad-hoc signed, no notarization. Browser host registration separate.
- Supply chain: pinned action SHAs; weekly Dependabot. Automatic GITHUB_TOKEN; no extra secrets. Archives uploaded without recompression; seven-day retention. Browser has no dependencies; no npm install.
