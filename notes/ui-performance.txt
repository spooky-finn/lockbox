Typing path
- Field edits replace only the affected buffer, with zeroizing input ownership.
- No whole-entry/attachment clone for each input event.
- Unchanged input does not postpone autosave.
- Generic multi-field commands retain snapshot comparison for correctness.

Constraints
- Preserve encrypted formats, transactional persistence and lock-time cleanup.
- Do not lower password derivation costs to disguise UI latency.
- Keep independent changes in separate commits; measure before broad rewrites.

Implemented
- Typed transient editor controls avoid cloning records when toggling panels,
  revealing fields, or filtering icons. These controls never schedule persistence.
- App-shell lock/title memos avoid root updates for unrelated session changes.
- Tree metadata equality memo reuses its rendered VNode across draft updates.
  The key stores only display metadata and search decisions, not secret fields.
- Browser-local arrow/Home/End focus navigation; Enter/Space activate records.
  Listener cleanup, disabled rows, modifier keys, folder boundaries tested.
- Classic/Ocean/Forest/Plum palettes, automatic light/dark variants, optional
  surface gradients, legacy custom-color compatibility, English/Russian labels.
- Contrast tests cover semantic text at 4.5:1 on all curated surfaces.
- Successful first durable save emits one brief spark burst and status message.
  Failed/invalid saves and subsequent edits do not celebrate; reduced motion
  hides particles and retains a static, automatically dismissed status.
- docs/ui-architecture.md defines ownership, reactive work, and future profiling.
