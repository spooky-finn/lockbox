UI performance and architecture — 2026-11-16

Branch: dev/ui-performance-and-architecture
Scope: editor responsiveness, tree navigation, curated themes, save feedback.
Caveman plugin unavailable in this session; repository note used as fallback.

Typing path
- Field edits replace only the affected buffer, with zeroizing input ownership.
- No whole-entry/attachment clone for each input event.
- Unchanged input does not postpone autosave.
- Generic multi-field commands retain snapshot comparison for correctness.

Constraints
- Preserve encrypted formats, transactional persistence and lock-time cleanup.
- Do not lower password derivation costs to disguise UI latency.
- Keep independent changes in separate commits; measure before broad rewrites.

Implemented
- Typed transient editor controls avoid cloning records when toggling panels,
  revealing fields, or filtering icons. These controls never schedule persistence.
- App-shell lock/title memos avoid root updates for unrelated session changes.
- Tree metadata equality memo reuses its rendered VNode across draft updates.
  The key stores only display metadata and search decisions, not secret fields.
- Browser-local arrow/Home/End focus navigation; Enter/Space activate records.
  Listener cleanup, disabled rows, modifier keys, folder boundaries tested.
- Classic/Ocean/Forest/Plum palettes, automatic light/dark variants, optional
  surface gradients, legacy custom-color compatibility, English/Russian labels.
- Contrast tests cover semantic text at 4.5:1 on all curated surfaces.
- Successful first durable save emits one brief spark burst and status message.
  Failed/invalid saves and subsequent edits do not celebrate; reduced motion
  hides particles and retains a static, automatically dismissed status.
- docs/ui-architecture.md defines ownership, reactive work, and future profiling.

UI performance — 2026-11-17

Found
- Draft keystrokes notified shared Session.
- Sidebar metadata key cloned/scanned all records on each notification.
- Selection/expansion repeated hierarchy projection and sorting.
- Folder selector rebuilt paths/sorted options during draft typing.
- Entry card subscribed to one-second clock; TOTP repainted whole card.
- Clipboard success wrote Session; pending click token also triggered render.
- Explicit save cloned validated draft twice, including attachments.

Changed
- Vault-local records revision invalidates metadata on commands, verified projection install, rollback.
- Revision never serialized; no signing, persistence or encryption semantics changed.
- Metadata scans only on record/query changes. Cache display hierarchy: IDs/names only.
- Selection/expansion reuse hierarchy. Search independently updates expansion even when rows equal.
- Folder options cached by revision/excluded folder. Icon search cached by query.
- TOTP owns clock subscription. Copy indicator expiry uses scoped timer.
- Clipboard success publishes status only; errors update Session when changed.
- Pending click cancellation uses nonreactive token. Explicit save validates without second snapshot.
- Visible Save button; Cmd/Ctrl+S uses physical KeyS for non-Latin layouts.
- Repeated/composing keystrokes ignored; Escape preserves existing save/discard/cancel flow.
- Reading/editing hints, keyboard-accessible title/notes, empty value targets, copy feedback.
- Match heading/field geometry; inline TOTP controls; compact notes; narrow-screen dialog bounds.
