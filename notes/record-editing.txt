Record autosave contract

- Draft owns 600 ms idle deadline. Field changes reset deadline; record mutations schedule through edit_draft. Attachment picker schedules after target checks and successful add.
- Reveal, generator visibility, icon search stay transient; draft_control schedules no writes.
- Runtime checks deadline without reactive writes. Due save persists validated snapshot through existing encrypted transactional Vault path; editor and controls remain owned by Draft.
- Navigation flushes immediately; success permits switch, failure keeps draft and selection, exposes error. No save/discard decision for ordinary navigation.
- Lock and window close retain existing final flush, then clear secrets. Invalid or failed flush retains existing locked-screen loss notice; no plaintext draft recovery.
- Failed timed save stops timer; next record edit or navigation retries. Empty untouched draft creates no record. Unchanged snapshot creates no revision.
- Tradeoff: durable encryption remains synchronous on UI thread after idle pause. Debounce avoids per-keystroke writes; large vault saves can still briefly stall UI.
