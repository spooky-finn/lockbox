1. Создайте проект в консоли Storj и отдельный bucket для Lockbox. Для нового bucket используйте 3–63 символа: строчные латинские буквы, цифры и дефисы; начало и конец — буква или цифра.

2. В разделе Access Keys выберите New Access Key и тип S3 Credentials. Назовите доступ так, чтобы отличать его от других приложений.

3. Выберите Advanced и ограничьте доступ выбранным bucket. Для планируемого обмена объектами Lockbox нужны Read, Write и List. Настройте срок действия доступа под свои требования.

4. Выполните шаг настройки encryption passphrase в Storj. Эта фраза относится к Storj; мастер-пароль локального профиля Lockbox задаётся отдельно.

5. Сохраните выданные Access Key, Secret Key и Endpoint. В форме Lockbox поле Base URL — это Endpoint gateway, без имени bucket и без пути. Укажите bucket в отдельном поле Bucket.

6. Введите имя пользователя и отображаемое имя хранилища в Lockbox. Имя хранилища может отличаться от bucket и не задаёт права доступа.

После проверки полей задайте мастер-пароль локального профиля и отдельный пароль восстановления корневого ключа, затем выберите место для файла .lbx. Имена, credentials и ключи сохраняются внутри зашифрованного профиля. Новые профили обмениваются зашифрованными подписанными событиями через Storj после открытия; ошибка сети оставляет изменения на устройстве. Форма проверяет синтаксис, а фактические права проверяются при обмене. Не загружайте локальный профиль в общий bucket и не копируйте его на другое устройство для совместной работы. Подключение участников доступно через API движка; экраны приглашений ещё не реализованы. Формат обмена LBX-SYNC-0 экспериментальный.
