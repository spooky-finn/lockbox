1. Создайте проект в консоли Storj и отдельный bucket для Lockbox. Для нового bucket используйте 3–63 символа: строчные латинские буквы, цифры и дефисы; начало и конец — буква или цифра.

2. В разделе Access Keys выберите New Access Key и тип S3 Credentials. Назовите доступ так, чтобы отличать его от других приложений.

3. Выберите Advanced и ограничьте доступ выбранным bucket. Для планируемого обмена объектами Lockbox нужны Read, Write и List. Настройте срок действия доступа под свои требования.

4. Выполните шаг настройки encryption passphrase в Storj. Эта фраза относится к Storj; мастер-пароль локального профиля Lockbox задаётся отдельно.

5. Сохраните выданные Access Key, Secret Key и Endpoint. В форме Lockbox поле Base URL — это Endpoint gateway, без имени bucket и без пути. Укажите bucket в отдельном поле Bucket.

6. Введите имя пользователя и имя хранилища в Lockbox. Выберите уникальное имя в пределах bucket: объекты S3 используют ключи spaces/<имя хранилища>/objects/. Имя может отличаться от bucket и не задаёт права доступа. Оно отображается в заголовке и на экране разблокировки, а подписанное приглашение передаёт его новым участникам.

После проверки полей задайте один мастер-пароль и сохраните 12 слов восстановления: слова и файл хранилища или его резервная копия восстановят доступ без старого пароля. Приложение сохранит файл .lbx в вашем личном каталоге ~/.lockbox. Credentials и ключи сохраняются внутри зашифрованного профиля. Имя хранилища также хранится в локальных настройках для экрана разблокировки и видно в ключах S3 и подписанных приглашениях. Новые профили обмениваются зашифрованными подписанными событиями через Storj после открытия; ошибка сети оставляет изменения на устройстве. Форма проверяет синтаксис, а фактические права проверяются при обмене. Не загружайте локальный профиль в общий bucket и не копируйте его на другое устройство для совместной работы. Для подключения к общему пространству выберите «Подключиться к пространству» на стартовом экране и укажите свои credentials для хранилища владельца. Имя хранилища вводить не нужно. Затем обменивайтесь файлами в «Участники и доступ»; Мастер показывает действие текущего шага и определяет тип файла автоматически. Скопируйте сообщение с username, User ID и Device ID и передайте администратору через второй доверенный канал, отдельно от файла запроса. Формат обмена экспериментальный, без версии. Прежние версии не поддерживаются.
